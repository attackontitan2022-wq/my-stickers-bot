# Sticker Archive Bot

بوت تيليجرام لأرشفة حزم الملصقات والإيموجي، يدعم العربية والإنجليزية.

## الميزات
- البحث بالأمر أو الوضع المضمن
- فهرس حروف A-Z
- بحث سهل بالشخصيات
- إضافة حزم عادية وبريميوم
- بلاغات، حظر، بث، نسخ احتياطي
- إشعارات، فيديو شرح

## التشغيل
```bash
pip install -r requirements.txt
python main.py
